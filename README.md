### 2. 📱 SMS Spam Detection

A Natural Language Processing and Machine Learning project that classifies SMS messages as either **Ham** or **Spam**.

The project uses **CountVectorizer** for text feature extraction and **Logistic Regression** for classification.

**Technologies:**
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Jupyter Notebook
- Natural Language Processing
- Machine Learning

**Model Performance:**
- Test Accuracy: **97.49%**
- Dataset: **5,572 SMS messages**
- Ham: **4,825**
- Spam: **747**

📁 [`SMS-Spam-Detection`](./SMS-Spam-Detection/)
